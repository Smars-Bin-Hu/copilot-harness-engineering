# Harness Engineering: The Engineering Outside the Model

A book on harness engineering: the rules, guardrails and tooling that turn a coding agent into something you can trust with real work. Every example runs on VS Code Copilot, from a real, open-source harness: [copilot-agentic-harness](https://github.com/Smars-Bin-Hu/copilot-agentic-harness).

## Start here

Clone this repository, open it in VS Code with GitHub Copilot (Claude Code and Codex work too), and say:

```text
Teach me harness engineering. Start from the map.
```

The `harness-engineering-tutor` skill takes it from there: it teaches one small piece at a time, stops for your questions, and gives you things to try. Short of time? Ask it for the core path: 17 chapters that carry the main line.
